# Spring Boot Interview Topics

Study documents generated by the `spring-boot-interview` agent (`/interview <topic>`).

Each document follows the same shape — short answer, concept, how it works, usage, comparison
tables, pitfalls, where it is applied in this repo, follow-up questions — written in plain
language and kept short. Every topic is also applied to real code in one of the practice
projects, and that code carries a comment linking back to its document:

```bash
grep -rn "Interview topic:" ../../
```

## Layout

Documents are filed by subject area, numbered per folder:

```
docs/interview/
  <topic>/            spring-core, spring-boot, spring-data-jpa, spring-security,
    01-<slug>.md      database, aws, java-core, concurrency, testing,
    02-<slug>.md      microservices, docker, messaging, performance
```
